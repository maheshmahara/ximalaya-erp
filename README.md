# Ximalaya Coffee Group (XCG) Enterprise ERP/CRM

Multi-Entity Monorepo for Vertically Integrated Specialty Coffee Operations:
- **Parent Holding**: Ximalaya Coffee Group
- **Procurement Co.**: Upstream sourcing, EUDR PostGIS plot geofencing, 8h pulping rule
- **Processing Co.**: Wet mill fermentation (pH 3.8-4.2), bed drying (10-12%), dry milling, XROS webhook, SCA Cupping
- **Sales & Marketing Co.**: B2B wholesale CRM, 13% VAT gapless IRD tax invoices, Drip Box BOM costing, public trace QR
